# portfolio

Personal portfolio — Astro 5 + Tailwind 3, static site → [munrhalls.com](https://munrhalls.com)

```bash
npm ci            # install
npm run dev       # dev server → http://localhost:4321
npm run build     # type-check + build → dist/
npm run preview   # serve the build
```

- `src/` — pages, components, layouts, styles, images
- `public/` — static files served as-is
- `design/` — design mockups and spec (`DESIGN.md`)
- `assets/` — raw image assets (design sources, project screenshots)
- `_project/` — agent campaign docs (see `AGENTS.md`)
